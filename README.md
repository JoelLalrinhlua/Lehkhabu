# Lehkhabu

AI-powered book marketplace.

## Structure
- `frontend-user`: User-facing React application.
- `frontend-admin`: Admin dashboard for managing books and users.
- `backend-api`: Main FastAPI service for business logic.
- `backend-ai`: AI services for book processing (Phase 2).
- `shared`: Shared TypeScript types.

## Development
Run `make dev` to start all services.
